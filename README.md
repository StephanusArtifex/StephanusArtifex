# Steve Muganda

### Data Analytics · Data Science · Data Engineering · Machine Learning · Deep Learning · AI Engineering

> **From raw data to reliable intelligence: from query and dashboard to pipeline, model and deployed AI system.**

My work lies at the confluence of **data analysis, data engineering and artificial intelligence**. Sound analysis begins with sound data. Strong models depend on sound engineering. Useful AI is founded upon both.

My foundation is **SQL** for querying and transforming relational data, and defining database schemas; **Python** for analysis, automation, modelling and AI systems.

I work across business intelligence, statistics, data engineering, machine learning, deep learning and AI engineering.

---

## The Confluence

| Discipline | Focus |
|---|---|
| **Data Analytics** | Querying, modelling, visualisation and decision support |
| **Data Science** | Statistical inference, experimentation and predictive modelling |
| **Data Engineering** | Pipelines, orchestration, warehousing and distributed processing |
| **Machine Learning** | Supervised and unsupervised learning, evaluation and feature engineering |
| **Deep Learning** | Neural networks, representation learning and transformers |
| **AI Engineering** | LLMs, retrieval systems, inference APIs and production deployment |

One continuum:

**Data → Structure → Analysis → Models → Intelligence → Systems**

---

## Core Languages

**SQL · Python**

**SQL** and **Python** are my core languages.

- **SQL:** querying, joins, aggregations, CTEs, window functions, DDL and query optimisation
- **Database design:** relational modelling, schema design and normalisation
- **Python:** data manipulation, automation, statistical computing, machine learning, APIs and AI systems
